# Lumen Shelf

Smart restocking for ERPNext v13 to v16. It learns how fast each item sells in
each outlet, works out how many days are left on the shelf, and suggests what
to transfer between warehouses and what to buy, before anything runs out.

Phase 1 is read only: it shows lists and creates no document.

See [docs/user-guide.md](docs/user-guide.md).
